# PeerSync

**A Multi-University Academic Collaboration Platform**

PeerSync helps students, professors, researchers, and industry partners find the right academic collaborator — based on verified skills and compatibility, not chance.

---

## The Problem

Finding a good teammate, mentor, or research partner at university is mostly luck. Students default to whoever they already know instead of who they'd actually work well with. Instructor-assigned groups solve fairness but ignore fit — mismatched work ethics, schedules, and skill levels are common. General-purpose tools like WhatsApp or Discord don't help either: they're built for people who already know each other, with no way to discover a new collaborator, verify they're a real student, or see how they performed on past projects.

Professors, researchers, and mentors face a version of the same problem — cross-departmental and inter-university collaboration still happens mostly through personal networks and conference hallway conversations.

## What PeerSync Does

PeerSync started as a swipe-based matchmaking tool for AIUB students and has grown into a multi-university platform serving five roles:

- **Students** — build a skill-tagged profile, search for collaborators by university/major/skills/course code, post team vacancies, message teammates, and rate each other post-project to build a persistent Karma score
- **Professors** — verify their faculty identity, list research interests and open thesis positions, run a private lab workspace, and search for students or faculty across institutions
- **Researchers** — sync publications via ORCID/Google Scholar, run encrypted project "sandbox vaults," post crowdsourced research calls, and find cross-disciplinary partners
- **Industry Partners** — post sponsored challenges and hackathons, search the talent pool by skill and Karma tier, and issue industry-endorsed performance scores
- **Admins** — verify accounts, moderate reports, manage the institutional email whitelist, and monitor platform-wide analytics

## Core Features

| Area | Highlights |
|---|---|
| Registration & Verification | Institutional/corporate email verification, role-based access control |
| Discovery | Advanced filtering by university, major, skills, course code, research interest |
| Collaboration | Project/vacancy posting, join requests, team dashboards |
| Messaging | Real-time 1:1 and group chat, quick-share for repo/cloud links |
| Reputation | Multi-criteria peer ratings, Karma scores, global and campus leaderboards |
| Research Tools | ORCID sync, private research workspaces, milestone timelines |
| Admin & Moderation | MFA-secured dashboard, report queue, domain whitelist, maintenance mode |

## Process

Development follows **Agile Scrum**, chosen for its fit with a multi-role system whose requirements evolve as feedback comes in. The project runs across nine phases — planning, analysis, design, four two-week sprints, testing, and final review/delivery.
